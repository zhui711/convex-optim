# 第一次作业：课件对齐、理论推导与数值设置

本项目仅对应用户提供的两张第一次作业截图：二次函数题和三指数非二次函数题。
课件第 80 页属于第二次作业，本项目不包含 Newton 方法。
本文页码均指用户提供的《第三章：无约束优化问题(2).pdf》的 PDF 物理页码。

## 1. 课件规定什么，哪些数值是实验选择？

| 类型 | 内容 |
|---|---|
| 课件与题面规定 | 目标函数、未归一化负梯度方向、精确搜索/回溯的定义、第一题初值规则、第二题所有配置使用同一初值 |
| 本项目的实验选择 | 第二题初值 `(1,1)`、回溯参数网格、主梯度容差 `1e-6`、一维数值搜索容差 |
| 数值运行得到 | 各组实际更新次数、轨迹、误差、评估次数及参数影响 |

课件第 19、21、26 页给出停止条件 $\|\nabla f(x^{(k)})\|_2\le\varepsilon$，但没有指定 $10^{-6}$ 或 $10^{-8}$。
本项目两题统一采用 $\varepsilon_g=10^{-6}$；这个数值可在配置中修改，不能写成老师指定的要求。

第一阶段方案曾对第一题用相对函数误差、第二题用梯度范数作为主停止条件。
两者是不同量，不能通过指数大小比较精度。第二阶段已经统一了主停止规则：

$$\boxed{\|\nabla f(x^{(k)})\|_2\le\varepsilon_g=10^{-6}.}$$

另设 $\varepsilon_R=10^{-8}$，只统计第一题的归一化函数误差 $R_k$ 首次达到该阈值的轮数，以去除不同初始尺度的影响。
它不是第一题另一套主停止条件。内层步长容差 $\varepsilon_t=10^{-12}$ 控制每一轮数值精确搜索的计算精度，也不是外层停止条件。

## 2. 精确搜索与 PPT 完全相同的定义

课件第 15、21 页定义：

$$d_k=-g_k=-\nabla f(x^{(k)}),\qquad
t_k=\arg\min_{t\ge0} f(x^{(k)}+t d_k),\qquad
x^{(k+1)}=x^{(k)}+t_kd_k.$$

它回答“应当选择哪个步长”，没有规定如何在计算机里完成这个一维最小化。
第一题的步长有解析式。第二题定义 $\phi_k(t)=f(x^{(k)}-t g_k)$，由链式法则：

$$\phi_k'(t)=-g_k^\top\nabla f(x^{(k)}-t g_k),$$

$$\phi_k''(t)=g_k^\top H(x^{(k)}-t g_k)g_k>0\quad(g_k\ne0).$$

所以 $\phi_k'$ 严格递增，且 $\phi_k'(0)=-\|g_k\|^2<0$。
本题沿非零方向最终趋于无穷，存在唯一正数使 $\phi_k'(t)=0$；它就是上述 `argmin` 的答案。

本项目用容易逐行解释的区间二分计算这个唯一正根：先括住根，再反复折半区间，根据导数正负保留根所在的一半。
二分是“如何算出课件规定的步长”的内层数值手段。它没有改变负梯度方向，也没有把外层算法改成另一种优化方法。

内层以步长区间宽度控制精度，不以固定的 $|\phi'(t)|\le10^{-12}$ 提前停止。
后者在外层接近 $\|g\|\approx10^{-6}$ 时可能误把 $t=0$ 当成足够准确的根，因为此时 $|\phi'(0)|$ 本来就约为 $10^{-12}$。

精确搜索的一阶最优性还给出：

$$\boxed{g_k^\top g_{k+1}=0.}$$

该性质用来解释路径和核验程序。数值实现中检查归一化内积接近零。

## 3. 第一题的理论基准

$$f_\gamma(x)=\tfrac12(x_1^2+\gamma x_2^2),\quad
A=\operatorname{diag}(1,\gamma),\quad g=Ax,\quad H=A.$$

$\gamma>0$ 保证 $A$ 正定，唯一最优解为 $x^\star=0$、$f^\star=0$。
沿负梯度展开：

$$f(x-tg)=f(x)-t g^\top g+\tfrac12t^2g^\top Ag.$$

对 $t$ 求导为零，得到一般精确步长：

$$t_k=\frac{g_k^\top g_k}{g_k^\top A g_k}.$$

课件第 32 页指定 $x^{(0)}=(\gamma,1)^\top$。由归纳法，该轨迹上 $t_k=2/(1+\gamma)$，且令 $q=(\gamma-1)/(\gamma+1)$：

$$x^{(k)}=q^k(\gamma,(-1)^k)^\top,$$

$$f(x^{(k)})=\frac{\gamma(\gamma+1)}2q^{2k},\qquad
\|g_k\|_2=\sqrt2\gamma|q|^k.$$

因此：

$$\boxed{R_k=\frac{f(x^{(k)})}{f(x^{(0)})}=\rho^k,
\qquad\rho=q^2=\left(\frac{\kappa-1}{\kappa+1}\right)^2,
\qquad\kappa=\max\{\gamma,1/\gamma\}.}$$

$\gamma=1$ 时一步到零；$1/3\le\gamma\le3$ 时 $\rho\le1/4$；参数很大或很小时 $\rho$ 接近 1。
这些结论由解析证明成立，程序执行真实迭代后再与它们比较。

对于非零初值且 $\gamma\ne1$，主停止和相对误差首达的理论计数分别为：

$$K_g=\left\lceil\frac{\ln(\varepsilon_g/(\sqrt2\gamma))}{\ln|q|}\right\rceil,
\qquad K_R=\left\lceil\frac{\ln\varepsilon_R}{2\ln|q|}\right\rceil.$$

初始梯度已达标时取 $K_g=0$，$\gamma=1$ 且未初始达标时取 1。
倒数参数的 $R_k$ 相同，但初始绝对梯度 $\sqrt2\gamma$ 不同，所以 $K_g$ 可以不同；这并不违反条件数的对称规律。

## 4. 第二题的理论基准

$$a=e^{x_1+3x_2-0.1},\quad b=e^{x_1-3x_2-0.1},\quad c=e^{-x_1-0.1}.$$

$$g=\begin{bmatrix}a+b-c\\3(a-b)\end{bmatrix},\qquad
H=\begin{bmatrix}a+b+c&3(a-b)\\3(a-b)&9(a+b)\end{bmatrix}.$$

$H_{11}>0$ 且 $\det H=9[4ab+c(a+b)]>0$，因此函数严格凸。
由 $g_2=0$ 得 $a=b$，即 $x_2=0$；再由 $g_1=0$ 得 $2e^{2x_1}=1$，所以：

$$\boxed{x^\star=(-\ln2/2,0),\qquad f^\star=2\sqrt2e^{-0.1}.}$$

在最优点处：

$$H(x^\star)=\operatorname{diag}(f^\star,4.5f^\star).$$

这里的条件数 4.5 是局部值，不代表整个平面。
函数不是全局强凸：沿 $(-s,0)$，$H_{22}=18e^{-s-0.1}\to0$。
但是迭代所在的子水平集是紧集，Hessian 在该集合上有正的统一下界和有限上界，符合课件在集合 $S$ 上进行收敛分析的设定。

第二题采用共同初值 `(1,1)`，以保留完整二维过程。
若 $x_2^{(0)}=0$，则 $g_2=0$ 始终成立，问题退化为横轴上的一维搜索，精确搜索可一步到最优点。
课件第 34 页没有给出绘图所用初值的具体坐标，因此本项目不声称逐点复刻那张示意图的迭代次数。

## 5. 回溯及可检验的参数机制

按课件第 26 页，每轮从 $t=1$ 开始。失败时令 $t\leftarrow\beta t$，直到：

$$f(x-tg)\le f(x)-\alpha t\|g\|^2,\quad0<\alpha<0.5,\quad0<\beta<1.$$

定义实际下降相对于线性预测下降的比例：

$$A(x,t)=\frac{f(x)-f(x-tg)}{t\|g\|^2}.$$

Armijo 等价于 $A(x,t)\ge\alpha$；候选步长来自离散集合 $\{1,\beta,\beta^2,\ldots\}$。
因此不同 $\alpha$ 可能接受完全一样的步长，从而产生完全一样的轨迹。
同一点、同一候选网格下，增大 $\alpha$ 不会使接受步长更大；但不同轨迹的总更新次数不必随 $\alpha$ 单调变化。

在最优点附近，局部二次近似给出：

$$A(x,t)\approx1-\frac t2\frac{g^\top Hg}{g^\top g},\qquad
e_{2,k+1}\approx(1-t_k\lambda_2)e_{2,k},\quad\lambda_2=4.5f^\star.$$

若步长接近 $2/\lambda_2$，第二坐标的乘子接近 $-1$，可能正负振荡且收敛很慢。
这是将步长、参数、曲率和误差长尾联系起来的可检验解释，不预先假定哪组参数最好。

## 6. 稳定误差计算与评估成本

记 $u=x_1+\ln2/2$。直接相减 $f-f^\star$ 在最优点附近容易损失有效数字，采用代数等价的非负式：

$$f(x)-f^\star=f^\star\left[2\sinh^2(u/2)+e^u\sinh^2(3x_2/2)\right].$$

该式用于记录与绘图；主停止仍由梯度决定。回溯也采用代数等价的稳定函数差值，以执行同一个 Armijo 不等式。
所有稳定写法在 `problems.py` 中有推导说明，独立差分检查用于核验。

更新次数不等于总计算量。结果分别报告完整目标函数求值 `n_full_f`、外层梯度 `n_g`、内层方向导数 `n_slope` 和稳定差值 `n_delta` 评估次数，后处理的图表/核验计算不计入优化成本。
`n_f = n_full_f + n_delta`，所以不能再把 `n_f` 与 `n_delta` 相加。内层方向导数计算也使用梯度表达式，但只计入 `n_slope`，不重复计入外层的 `n_g`。
精确搜索每次接受步还计算一次稳定差值以记录下降比；这部分记录开销已计入 `n_delta`，并非理论上计算步长必需的开销。
不把不同类型的调用机械等同为运行时间，也不根据一次极短的二维运行计时断言某种方法普遍更高效。
